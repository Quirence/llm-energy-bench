# Конфигурации power-quality-v2

Этот каталог хранит только заранее зафиксированные условия второго эксперимента.
Один TOML описывает одну модель, один лимит мощности и один независимый запуск.
Менять TOML после начала производственной серии нельзя.

## Общие параметры

- runtime: Ollama `0.35.0`;
- модели: `llama3.2:3b-instruct-q4_K_M` и
  `qwen3:4b-instruct-2507-q4_K_M`;
- digest моделей: `a80c4f17…` и `0edcdef3…` соответственно;
- prompt set: `prompts/power-quality-v2.jsonl`, SHA-256 контракта
  `7d7d1ee71cacc1129d4076b18d5ceb630052950994acab18e112892194d099ff`;
- пять повторений каждого из 12 запросов;
- четыре прогрева, последовательное выполнение, `temperature=0`, `seed=42`,
  `num_ctx=4096`, `num_predict=256`, KV cache `f16`;
- три независимых запуска каждого условия;
- телеметрия NVML каждые 100 мс;
- допустимое отклонение power limit: 1 Вт.

## RTX 5060 Laptop — профиль снят 2026-10-02

- стенд: MAIBENBEN X16C, host id `maibenben-x16c-rtx5060`;
- GPU: NVIDIA GeForce RTX 5060 Laptop GPU, 8151 MiB;
- драйвер: 591.66;
- NVML: current/requested 80 Вт, default 50 Вт, minimum 5 Вт,
  maximum 115 Вт;
- при профилировании: 43 °C, VRAM 0 MiB, модель выгружена;
- total-energy counter, instantaneous/legacy power, temperature, utilization,
  clocks и power-limit telemetry доступны;
- обе Q4-модели установлены; Llama Q4 подтверждена как полностью размещённая
  в GPU; digest совпал;
- `doctor` для условия 80 Вт и Ollama 0.35.0 завершился с `ok=true`.

Зафиксированы уровни 80, 65, 50 и 35 Вт. Они входят в объявленный NVML
диапазон, но команда `nvidia-smi -pl` из обычной PowerShell получила
`Insufficient Permissions`. Поэтому до производственной серии оператор обязан
один раз проверить все четыре уровня из PowerShell, запущенной от имени
администратора, и выполнить аппаратную приёмку из runbook. До этой проверки
уровни 65/50/35 Вт считаются кандидатами, а не полученными измерениями.

В `rtx5060/` находятся 24 TOML: две модели × четыре уровня × три запуска.

Каталог `acceptance/` не входит в производственную матрицу: в нём по одному
повторению запроса для коротких smoke-run и намеренного fail-closed теста.
Его результаты хранятся отдельно под `power-quality-v2-acceptance`.

## RTX 4060 Ti и GTX 1080 — ожидаются профили

Точные minimum/default/maximum/current значения и возможность выполнить
`nvidia-smi -pl` должны прислать Лев и Дима по отдельным заданиям в `docs/`.
До получения этих данных каталоги `rtx4060ti/` и `gtx1080/` намеренно не
создаются: угадывать уровни мощности нельзя. После профилей конфигурации
создаёт и замораживает Quirence/Codex; коллеги не редактируют TOML вручную.

GTX 1080 имеет роль `external`. Её результаты показываются отдельно и не
объединяются с двумя основными GPU.
