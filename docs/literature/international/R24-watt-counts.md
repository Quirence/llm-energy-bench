# R24. Watt Counts

**Источник:** M. F. Argerich, J. Fürst, M. Patiño-Martínez. “Watt Counts:
Energy-Aware Benchmark for Sustainable LLM Inference on Heterogeneous GPU
Architectures.” 2026. [arXiv](https://arxiv.org/abs/2604.09048).

**Статус чтения:** полный текст прочитан. **Уровень:** C, препринт.

## Эксперимент

Открытый набор включает более 5000 экспериментов: 50 моделей, 10 NVIDIA GPU
пяти архитектур, 370+ пар модель–GPU, пакетный и серверный режимы vLLM.
Энергия GPU измеряется EnergyMeter/NVML с частотой 10 Гц. Каждая конфигурация
повторяется пять раз; контролируются прогрев и охлаждение.

В пакетном режиме H100 был лучшим по энергии на токен примерно для 90%
моделей, но исключения зависели от размера. Для малых моделей низкая мощность
L4/A30 могла компенсировать меньшую скорость. Паспортные FLOPS/Вт оказались
плохим заменителем измеренной энергии на токен.

Смешанная модель показала, что размер модели — главный фактор; после его учёта
большее число голов ключей/значений и внимания связано с ростом энергии,
большая ширина при том же числе параметров — со снижением, а глубина дала
слабый пограничный эффект. Авторы подчёркивают взаимодействие модели, GPU и
сценария обслуживания.

## Связь с нашей работой

Это наиболее сильный источник для вопроса «почему архитектура и TDP не дают
простого процента». Он также ограничивает нашу новизну: широкое сравнение GPU
уже существует.

Watt Counts использует только 16-битные веса и сознательно исключает качество.
Авторы называют квантование и совместную оптимизацию качества будущей работой.
Наша меньшая матрица закрывает эти два аспекта для локального Ollama и добавляет
изменяемый лимит мощности.
