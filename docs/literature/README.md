# Литературная база статьи

Дата проверки: 14 октября 2026 года.

Эта папка фиксирует литературную часть первого этапа статьи. Здесь хранятся
не копии публикаций, а русскоязычные карточки чтения с прямыми ссылками на
оригиналы. Такой формат не нарушает права издателей и позволяет быстро
проверить, откуда взято каждое утверждение.

## Что считается прочитанным

В карточке каждого источника указан один из статусов:

- **полный текст прочитан** — проверены постановка задачи, методика,
  результаты, ограничения и заключение;
- **прочитаны основные разделы** — проверены методика, результаты и
  ограничения, но источник не используется для тонких библиографических
  утверждений;
- **предварительный источник** — доступна аннотация или короткий материал;
  он не используется как основное доказательство.

## Уровни доказательности

- **A** — рецензируемая публикация с близким эмпирическим экспериментом;
- **B** — рецензируемая публикация, поддерживающая часть методики или
  интерпретации;
- **C** — содержательный препринт или материал конференции;
- **D** — концептуальная или предварительная работа, пригодная только для
  описания контекста.

Статус рецензирования не выводится из качества результатов: препринты явно
помечаются препринтами, даже если их эксперимент сильнее отдельных журнальных
работ.

## Главное правило

Числа из чужого эксперимента не используются как ожидаемые значения для
нашего оборудования. Они нужны для сопоставления постановок, методов и границ
применимости. Любое численное сравнение сопровождается указанием различий в
GPU, среде выполнения, модели, разрядности, типе нагрузки и границе измерения.
