# R15. Прогрев и установившийся режим

**Источник:** A. Georges, D. Buytaert, L. Eeckhout. “Statistically Rigorous
Java Performance Evaluation.” OOPSLA 2007.
[Открытый текст](https://users.elis.ugent.be/~leeckhou/papers/oopsla07-stat.pdf),
[DOI](https://doi.org/10.1145/1297027.1297033).

**Статус чтения:** прочитаны основные разделы. **Уровень:** B.

## Полезный результат

Авторы отделяют начальную и установившуюся производительность, используют
несколько запусков и интервальные оценки. Главный урок — начальные измерения
динамической системы нельзя молча смешивать со стабильным режимом.

## Связь с нашей работой

Ollama и GPU не являются JVM, поэтому конкретные процедуры статьи не
копируются. Общий принцип реализован загрузкой модели и двумя прогревочными
запросами до измеряемой серии; холодная загрузка сохраняется отдельно и не
входит в показатель прогретого запроса.
