# R18. LLM.int8()

**Источник:** T. Dettmers et al. “LLM.int8(): 8-bit Matrix Multiplication for
Transformers at Scale.” NeurIPS 2022.
[Страница публикации](https://papers.neurips.cc/paper_files/paper/2022/hash/c3ba4962c05c49636d4c6206a97e9c8a-Abstract-Conference.html).

**Статус чтения:** полный текст прочитан. **Уровень:** A.

## Полезный результат

Метод сочетает векторное восьмибитное умножение для основной массы значений с
16-битной обработкой редких выбросов. Это сокращает память для очень крупных
трансформеров, сохраняя качество в исследованных авторами условиях.

## Связь с нашей работой

LLM.int8() не равен GGUF Q8_0: отличаются представление весов, обработка
активаций, ядра и масштаб моделей. Источник подтверждает, что название
«8 бит» недостаточно для прогноза скорости, энергии или качества конкретной
среды выполнения.
