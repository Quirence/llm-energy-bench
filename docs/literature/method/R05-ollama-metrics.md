# R05. Показатели Ollama

**Источник:** Ollama. “API usage metrics.”
[Официальная документация](https://github.com/ollama/ollama/blob/main/docs/api/usage.mdx).

**Статус чтения:** документ прочитан. **Уровень:** технический первоисточник.

## Что фиксирует источник

Итоговый ответ Ollama содержит общую длительность, время загрузки, длительности
обработки входа и генерации, а также соответствующие количества токенов.
Длительности передаются в наносекундах. Потоковый интерфейс позволяет отдельно
измерить время до первого содержательного фрагмента.

## Связь с нашей работой

Счётчики среды выполнения сохраняются рядом с собственными монотонными
временными метками. Скорость обработки входа и генерации рассчитывается по
своим фазам; общая задержка не подменяется суммой выбранных полей без проверки
итогового ответа.
