# R19. Технический отчёт Qwen3

**Источник:** Qwen Team. “Qwen3 Technical Report.” 2025.
[Открытый текст](https://arxiv.org/abs/2505.09388).

**Статус чтения:** прочитаны основные разделы. **Уровень:** C, технический
отчёт.

## Полезный результат

Отчёт описывает семейство Qwen3, режимы рассуждения, обучение и результаты
исходных моделей. Он нужен для корректного обозначения семейства и понимания,
что варианты разных размеров и режимов не являются взаимозаменяемыми.

## Связь с нашей работой

Мы исследуем конкретный вариант Qwen3 4B Instruct с зафиксированным цифровым
отпечатком и шаблоном Ollama. Результат не распространяется на другие размеры,
полную точность, режим рассуждения или обновлённые сборки с тем же коротким
названием.
