# R04. Справочник NVML

**Источник:** NVIDIA. “NVML API Reference Guide.”
[Официальная документация](https://docs.nvidia.com/deploy/nvml-api/latest/).

**Статус чтения:** релевантные разделы документа прочитаны. **Уровень:**
технический первоисточник.

## Что фиксирует источник

NVML предоставляет мощность, накопленную энергию на поддерживаемых устройствах,
температуру, память и предел мощности. Единицы и доступность зависят от функции,
драйвера и поколения GPU; отсутствие счётчика должно обрабатываться явно.

## Связь с нашей работой

Стенд сначала проверяет возможности устройства, затем выбирает накопленный
счётчик энергии или численное интегрирование мощности. NVML описывает смысл
показателей, но не гарантирует точность уровня внешнего ваттметра и не измеряет
весь компьютер.
