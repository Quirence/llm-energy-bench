# M03. Руководство MLCommons по измерению мощности

**Источник:** MLCommons. “Power Measurement.”
[Официальное руководство](https://docs.mlcommons.org/inference/power/).

**Статус чтения:** документ прочитан. **Уровень:** технический первоисточник.

## Роль в статье

Руководство описывает практическую схему внешнего измерения мощности,
подключение поддерживаемых приборов и согласование измерений с нагрузкой. Оно
задаёт ориентир для будущей проверки программной телеметрии.

Текущие результаты ограничены энергией GPU по NVML. Без параллельного внешнего
измерителя они не используются для вывода о полной энергии компьютера, потерях
блока питания или абсолютной погрешности программного счётчика.
