# R13. Правила измерения мощности MLPerf

**Источник:** MLCommons. “MLPerf Inference Power Measurement Rules.”
[Исходный документ](https://github.com/mlcommons/inference_policies/blob/master/power_measurement.adoc).

**Статус чтения:** документ прочитан. **Уровень:** технический первоисточник.

## Полезный результат

Правила MLPerf описывают синхронизацию нагрузки и измерителя, допустимые
внешние измерительные приборы, устойчивый интервал и требования к отчётности.
Их граница обычно охватывает систему шире отдельного GPU.

## Связь с нашей работой

Наш стенд не заявляет соответствие MLPerf: используется NVML и измеряется
только GPU. Документ нужен для точного ограничения результата и плана будущей
проверки внешним ваттметром, а не для присвоения нашим данным статуса полного
измерения системы.
