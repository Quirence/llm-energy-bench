# Резервные и исключённые материалы

Эти материалы были найдены при поиске, но не используются как основное
доказательство.

| Материал | Решение | Причина |
| --- | --- | --- |
| новости и обзоры без исходных данных | исключить | нельзя проверить методику и границу энергии |
| калькуляторы «энергии одного запроса» | исключить | скрыты модель, число токенов, GPU и допущения |
| паспортные таблицы GPU | только описание стенда | TDP и FLOPS/Вт не заменяют измеренную энергию |
| RU04, динамические микро-БЯМ | резервный контекст | концепция без реализованного эксперимента |
| RU05, Rockchip NPU | резервный контекст | краткий конференционный материал и другая платформа |
| учебный проект Measuring the True Energy Cost of Correct LLM Inference | не цитировать как науку | интересная демонстрация, но не рецензируемая публикация |
| публичные таблицы и сообщения сообществ LocalLLaMA | не цитировать как доказательство | полезны для поиска гипотез, но не обеспечивают научный контроль |

## Правило возврата источника в основной список

Материал можно перенести в основную карту, если доступен полный текст,
определены авторы и площадка, описаны оборудование, нагрузка, способ измерения,
число повторений и ограничения. Процент экономии без этих сведений не является
достаточным основанием.
